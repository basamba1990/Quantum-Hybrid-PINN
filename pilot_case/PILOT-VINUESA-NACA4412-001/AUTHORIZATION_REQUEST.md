# Demande d’autorisation — PILOT-VINUESA-NACA4412-001

## Objet

Demander au propriétaire ou gestionnaire des données l’autorisation écrite d’utiliser un sous-ensemble de données NACA4412 pour un pilote de recherche PINN-RANS classique et hybride/quantique.

## Données demandées

- Profil : NACA4412.
- Condition proposée : `Re_c = 200000`, basée sur `U_infinity` et la corde `c`, confirmée dans le README du cas NACA4412 ; les paramètres dimensionnels restent à confirmer dans les données autorisées.
- Variables demandées : coordonnées, vitesse moyenne, pression si disponible, contraintes de Reynolds et quantités intégrales disponibles.
- Finalité : recherche, comparaison reproductible d’une baseline classique et d’une variante hybride/quantique.
- Criticité : non critique pour la sécurité ; aucune décision opérationnelle.
- Conservation : fichiers originaux en lecture seule, avec taille et SHA-256.
- Publication : à confirmer séparément ; aucune redistribution sans autorisation explicite.

## Autorisation à obtenir

La réponse signée doit préciser :

1. l’identité du propriétaire ou représentant autorisé ;
2. les fichiers ou sous-ensembles autorisés ;
3. la licence ou base juridique d’utilisation ;
4. la finalité autorisée ;
5. les utilisateurs autorisés ;
6. la durée et la date de début ;
7. les règles de redistribution et de publication ;
8. les obligations de citation ;
9. les restrictions de données dérivées ;
10. la procédure de révocation ou de retrait.
