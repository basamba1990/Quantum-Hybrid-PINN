# LH2-TANK-TRANSIENT-RUN-001

This benchmark uses a closed analytic reconstruction of the 50 L LH2 tank described by Jeong et al. (Fluids 2023, 8, 239). It is not the author CAD. The executable validation case is incompressible laminar `pimpleFoam` with `snappyHexMesh`; thermo-boiling physics are not claimed.
